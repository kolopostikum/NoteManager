Тестовое задание на знание стека C++, Qt, SQLite, Linux, OOPI

Цель задания

Оценить практические навыки кандидата в разработке десктопного приложения на C++ с использованием Qt, работой с базой данных SQLite, пониманием принципов ООП и базовыми навыками работы в Linux.

Ориентировочное время выполнения: 3-5 часов.

Задание: «Менеджер заметок»

Разработать кроссплатформенное десктопное приложение NoteManager — простой менеджер заметок с сохранением данных в SQLite.

Функциональные требования

1. Главное окно:
• Список заметок (QListView / QTableView / QListWidget — на выбор).
• Поле поиска/фильтрации по заголовку.
• Кнопки: «Добавить», «Редактировать», «Удалить», «Обновить».
• Область предпросмотра выбранной заметки.

2. Диалог редактирования заметки:
• Поля: заголовок (обязательное), текст (многострочное), теги, дата создания/изменения (только для чтения).
• Валидация: заголовок не пустой, длина ≤ 100 символов.

3. Работа с БД (SQLite):
• Автоматическое создание файла БД и таблицы при первом запуске.
• CRUD-операции: создание, чтение, обновление, удаление заметок.
• Поиск по подстроке в заголовке и тексте.

4. Дополнительно:
• Экспорт выбранной заметки в .txt / .md.
• Сортировка по дате/заголовку.
• Горячие клавиши (Ctrl+N, Ctrl+S, Delete).

5. Автосохранение:
• Реализовать автосохранение заметки каждые 30 секунд при редактировании и восстановление несохранённых изменений при аварийном закрытии приложения.
• Продумать, где хранить черновики (отдельная таблица в SQLite / временный файл) и как избежать конфликтов.

Технические требования

C++ / OOPI

• Стандарт C++11,14,17.
• Обязательное применение принципов ООП:
- Инкапсуляция: разделение UI и логики работы с данными.
- Наследование: минимум один класс-наследник QDialog или QAbstractTableModel.
- Полиморфизм: интерфейс (абстрактный класс) для слоя доступа к данным, например:

class INoteRepository {
public:
    virtual ~INoteRepository() = default;
    virtual QVector<Note> getAll() = 0;
    virtual std::optional<Note> getById(int id) = 0;
    virtual bool add(const Note& note) = 0;
    virtual bool update(const Note& note) = 0;
    virtual bool remove(int id) = 0;
};

- Реализация SqliteNoteRepository : public INoteRepository.
- Использование умных указателей (std::unique_ptr, std::shared_ptr) вместо сырых new/delete.
- Отсутствие утечек памяти (проверяется через valgrind или AddressSanitizer).

Qt

• Qt 5.15.
• Использование сигналов/слотов, QSqlDatabase, QSqlQuery, QSqlError.
• Отсутствие блокирующих операций в UI-потоке (для данного задания не критично, но приветствуется QThread/QtConcurrent при экспорте).
• Ресурсы (иконки) — через .qrc.

SQLite

• Таблица notes:

CREATE TABLE IF NOT EXISTS notes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    content TEXT,
    tags TEXT,
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL
);

• Параметризованные запросы (prepare + bindValue) — обязательно, для защиты от SQL-инъекций.

Linux

• Сборка через CMake (предпочтительно) или qmake.
• Умение работать в терминале:
- Сборка проекта из командной строки.
- Запуск приложения.
- Проверка содержимого БД через sqlite3 CLI.
- Базовые команды (grep, find, ps, ldd для проверки зависимостей).
